# Optimisation

UFF4MOF geometry optimisation via `gulp_setup`'s atom-typing backend:
`cage_isomer_builder.utils.optimise`.

For organic molecules the energy matches RDKit's UFF implementation, term by
term. The tests check this on 16 molecules.
